# Local Git Project

This project demonstrates Git initialization,
file tracking, committing, and remote synchronization.

The experiment was successfully performed to understand and execute Git operations using GitHub and Visual Studio Code. A GitHub repository was created, Git was configured, and a remote repository was cloned into a local working directory. File creation, modification, deletion, staging, committing, pushing, and pulling operations were performed. A local repository was initialized using `git init` and connected to GitHub. Branch creation, switching, comparison, merging, and pull request operations were carried out. Finally, repository synchronization between the local working directory and the remote GitHub repository was verified.
